# Font Awesome Configuration

Detected by the Font Awesome agent tools. Commit this file so the whole team benefits.

## Integration

- **Method:** Web Fonts+CSS via `@fortawesome/fontawesome-free`
- **Version:** 7.3.1
- **License:** Free
- **Families:** classic

## Defaults

- **Style:** solid
- **Family:** classic

## Import Pattern

- Global CSS import in `src/mainview/main.ts`: `import "@fortawesome/fontawesome-free/css/all.min.css";`
- Icon markup in Svelte components: `<i class="fa-solid fa-{icon-name}"></i>` (or `fa-regular`, `fa-brands` for brand icons)

## Conventions

- Icons are embedded using semantic `<i>` tags with standard Font Awesome utility classes (`fa-solid fa-...`).
- Document type icon mappings:
  - `manuscript`: `fa-solid fa-book-open`
  - `character`: `fa-solid fa-user`
  - `plot`: `fa-solid fa-chart-line`
  - `world`: `fa-solid fa-map`
  - `note`: `fa-solid fa-file-lines`
